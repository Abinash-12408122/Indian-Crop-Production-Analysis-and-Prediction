# Indian-Crop-Production-Analysis-and-Prediction
# Indian Crop Production Analysis and Prediction Using Machine Learning

## Project Overview
This project analyses Indian crop production data using Python, data preprocessing, exploratory data analysis (EDA), and machine learning techniques.

The study examines crop production patterns across different states, districts, crops, seasons, and years from 1997 to 2022.

## Objectives
- Analyse Indian agricultural crop production data.
- Perform data cleaning and preprocessing.
- Conduct exploratory data analysis.
- Implement and compare seven regression approaches.
- Apply K-Means clustering to agricultural records.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Algorithms

### Regression
1. Simple Linear Regression
2. Multiple Linear Regression
3. Polynomial Regression
4. K-Nearest Neighbors Regression
5. Decision Tree Regression
6. Random Forest Regression
7. Linear Support Vector Regression

### Clustering
- K-Means Clustering
